# How to find simulation setups and raw data
The simulations folder contains two primary subfolders (Multi_Nanoparticle and Single_Nanoparticle) that hold the information needed to set up and run simulations. 

# Multi-Nanoparticle

The Multi_Nanoparticle folder contains 10_NP_Systems, which includes scripts and setups for running systems with 10 nanoparticles.
The folder is set up in the following format: [GNP core type]/[Ligand Type]/[Replica Number]/[Folders to run that simulation].
10_NP_Systems also contains the Dimerization_Free_Energy_System folder, which has the simulations for getting the dimerization free 
energy between two nanoparticles using umbrella sampling. The folder is set up in the following format: [GNP core type]/[Replica Number]/[All the files necessary to rerun an umbrella sampling dimerization free energy simulation]

# Single-Nanoparticle

The Single_Nanparticle folder contains simulation setups for nanoparticles with different core parameters.
The folder is set up in the following format: [GNP core type]/[Ligand Type]/[Replica Number]/[Folders to run that simulation].
